🔄 Workflow

How It Works

From raw satellite data to your personalised advisory report in four steps.

1

Data Ingestion

20 years of NASA POWER climate records, IMD rainfall data, and Soil Health Card readings are ingested and cleaned into a unified dataset.

2

Feature Engineering

200+ features are engineered — seasonal lags, rolling averages, drought indices, NDVI vegetation indices, and soil-climate interaction terms.

3

ML Prediction

XGBoost, Random Forest, LSTM, and Linear Regression models are trained per crop-district pair and ensemble-weighted for robust yield forecasts.

4

Advisory Output

SHAP values explain the prediction, a Folium map shows district insights, and a personalised PDF advisory report is generated instantly.

🤖 Machine Learning

Four Models,
One Reliable Forecast

Each model contributes its strength — ensembled for maximum accuracy across all crop-climate combinations.

Primary

XGBoost

Gradient boosted trees. Highest accuracy across all districts. Handles missing data, non-linear interactions, and feature importance natively.

94%
Ensemble

Random Forest

Bootstrap aggregation of 500 decision trees. Robust to outliers and provides variance estimates for prediction confidence intervals.

91%
Deep Learning

LSTM Network

Long Short-Term Memory RNN. Captures long-range temporal dependencies in multi-year climate sequences for trend-aware forecasting.

88%
Baseline

Linear Regression

Ridge-regularised baseline. Interpretable benchmark that performs well in data-sparse districts with fewer historical records available.

79%
